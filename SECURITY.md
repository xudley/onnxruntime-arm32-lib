# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please open an issue or contact me directly at GitHub.

I will acknowledge receipt within 48 hours and work on a fix as soon as possible.

## Security Best Practices

- Only use pre-built binaries from trusted sources (official GitHub releases)
- Verify checksums before deployment on embedded ARM devices
- Keep build toolchains and dependencies up to date
- No hardcoded secrets or API keys in the source code
